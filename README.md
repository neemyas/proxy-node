## About the Project

A lightweight HTTP streaming proxy built with Node.js,
Express and Axios.

The project handles HTTP requests and forwards streamed
responses between upstream servers and client applications.

## Features

- HTTP request forwarding
- Stream-based response handling
- Content-Type header forwarding
- CORS configuration
- Environment-based port configuration
- Basic error handling

## Technologies

- Node.js
- Express.js
- Axios
- JavaScript
- CORS
- HTTPS

## Architecture

Client Application → Proxy Server → Origin Server

## Project Structure

- `server.js` — Proxy server implementation
- `package.json` — Project dependencies

## Security Considerations

The current implementation requires additional security
controls before unrestricted public deployment, including
authentication, destination validation and TLS verification.
